# 🦸 Classificador de Nível de Herói

## 📖 Descrição
Projeto desenvolvido como parte do **Bootcamp Santander 2025 - Front-End (DIO)**.  
O objetivo é criar um programa em **JavaScript** que classifica um herói de acordo com sua experiência (**XP**).

---

## 🛠️ Tecnologias utilizadas
- **JavaScript** (linguagem principal)  
- **Node.js** 

---

## 🚀 Regras do Desafio
Crie uma variável para armazenar:
- **Nome** do herói  
- **Quantidade de experiência (XP)**  

Depois, utilize **estruturas condicionais** para classificar o herói nos seguintes níveis:

| Faixa de XP              | Nível        |
|---------------------------|-------------|
| Menor que 1.000           | Ferro       |
| 1.001 até 2.000           | Bronze      |
| 2.001 até 5.000           | Prata       |
| 5.001 até 7.000           | Ouro        |
| 7.001 até 8.000           | Platina     |
| 8.001 até 9.000           | Ascendente  |
| 9.001 até 10.000          | Imortal     |
| Maior ou igual a 10.001   | Radiante    |

---

## 🧩 Como funciona
O herói **ganha XP a cada missão** (simulado com um **laço de repetição**).  
Em cada passo, o programa mostra o **nome do herói**, seu **nível atual** e a **quantidade de XP**.
